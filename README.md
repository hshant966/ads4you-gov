## Overview

A premium multi-page proposal website showcasing how AI automation can transform Maharashtra government department operations. Designed for government officers, department heads, and decision-makers.

- **Default Language:** Marathi (शासकीय मराठी)
- **Default Theme:** Light (warm cream)
- **Bilingual:** Full Marathi ↔ English toggle
- **Theme:** Light ↔ Dark toggle with localStorage persistence

## Deployment

### GitHub Pages

```bash
git add .
git commit -m "deploy: complete 7-page Maharashtra AI proposal website"
git push origin main
```

Then enable Pages:
1. Go to `Settings → Pages`
2. Source: Deploy from branch
3. Branch: `main` / `(root)`
4. Save

Live in 60-90 seconds at: `https://hshant966.github.io/ads4you-gov`
